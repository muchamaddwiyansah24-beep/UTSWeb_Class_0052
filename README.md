## Deskripsi Project

Ngopi O Sek Pak De adalah sebuah website sederhana bertema kedai kopi yang dibuat untuk menampilkan menu, suasana, dan layanan dari sebuah coffee shop lokal. Project ini dibangun sebagai latihan pengembangan web menggunakan HTML, CSS, dan JavaScript dengan fokus pada tampilan yang menarik, responsif, dan mudah digunakan.
## Fitur Website

- Landing Page
- Menu Kopi & Makanan
- Desain Tema Coffee Shop
- Responsive Design
- Interaksi Sederhana (JavaScript)
- Galeri / Suasana Kedai
- Halaman kontak

## Teknologi yang Digunakan

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Manipulasi DOM

1. Dark Mode Toggle
2. Notifikasi Form
3. Filter Menu
4. Hover Effect DOM
